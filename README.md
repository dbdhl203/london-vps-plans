## 伦敦线路的真实构成：电信 CN2、联通 CN2、移动 CMIN2

约 200ms 的延迟，做文字后台、SSH、轻量 API 调用够用；实时游戏和直播推流会难受，晚高峰一抖动，体验掉得很快。

按测评文章的拆解，伦敦机房电信双程 CN2，联通回程强制 CN2，移动回程走 CMIN2。有些推广页直接写“三网回程 CN2 GIA”，这个说法不准确。CN2 GIA 是中国电信的线路产品，CMIN2 是移动国际专线，两家的东西不能合成一个名字。比价时看到“三网 CN2 GIA”，先问清楚移动回程到底走什么。

200ms 是测评参考值，不是官方 SLA。实际延迟看你所在省份、本地运营商和访问时段。三个机房放一起看更直观：圣何塞约 168ms、法兰克福约 180ms、伦敦约 200ms。伦敦是离国内最远的一个，选它通常是为了英国 IP 或欧洲落地。

带宽也要给预期。全系标 500Mbps 端口，测评文章实测下载最高约 60Mbps。端口规格是网卡能力，跨境实际吞吐受国际出口拥塞、时段和本地运营商影响，两者要分开看。拿它跑大流量下载或视频推流，按几十 Mbps 规划更稳。
